## 用法

- 判断 Deploy.log 的 `Unknown game version` 是不是"等更新"就能解决：查游戏当前版本，
  对表看是否有更新的 SMF。
- 平台差异：3.270.1 时 Microsoft（商店）版和 Steam/Epic 版是**分开两个版本**修的；
  3.250.1 只提了 Steam。
